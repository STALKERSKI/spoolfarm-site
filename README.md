# spoolfarm.ikkadoes.com

Public website for **SpoolFarm**, an Android application for running a 3D printing farm.

This repository contains only the static site — the landing page and the privacy policy
required by Google Play. The application source is not part of this repository.

- Landing page: https://spoolfarm.ikkadoes.com
- Privacy policy: https://spoolfarm.ikkadoes.com/privacy
- Privacy policy (Russian): https://spoolfarm.ikkadoes.com/privacy/ru/

Served by GitHub Pages from the `main` branch.
